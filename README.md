# 📖 Dictionary Web App

A responsive Dictionary Web App built using HTML, CSS, and JavaScript. This application allows users to search for the meaning of English words, along with pronunciation, phonetics, parts of speech, and example usage through a dictionary API.

## 📌 About the Project

The Dictionary Web App helps users quickly search for English words and view their meanings in a clean and user-friendly interface. It fetches real-time data from a dictionary API and displays detailed information about the searched word.

---

## ✨ Features

- 🔍 Search any English word
- 📖 View word meanings
- 🔊 Listen to pronunciation (if available)
- 📝 Display definitions and examples
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and easy-to-use interface
